Watch State Sync

Connection and users

Each enabled mapping uses its own Plex token. The Plex username defaults to the Jellyfin username but can differ.

Use the URL reachable from the Jellyfin server. In the Docker stack this is http://plex:32400.

Manual Plex → Jellyfin baseline

Plex is authoritative for uniquely path-matched movies and episodes. Applying a preview marks watched Plex items watched in Jellyfin and clears Jellyfin watched state for matched unwatched Plex items. Unmatched and ambiguous items are never changed.

A dry run is mandatory. Its preview expires after 15 minutes and is rejected if configuration, media, or watch state changes before apply.
